# 🚗 8891 中古車快速查詢與智慧估價系統

一套基於 **Python Tkinter GUI**、**SQLite 資料庫** 與 **CSV 數據管線** 的中古車資料檢索、自動化採集與市場行情分析桌面軟體。系統內建收錄自 8891 平台的近 4 萬筆車源大數據，提供直覺的多維度車源篩選、表格檢視、欄位表頭排序、雙擊瀏覽器直達車源頁面、雙軌 CSV 讀寫，以及基於大數據統計的「二手車行情智慧估價與歷史報表」功能。

專案代碼庫：[https://github.com/jerrybottw-afk/8891-app](https://github.com/jerrybottw-afk/8891-app)

## 🌟 系統特色

1. **多維度車源篩選、排序與雙擊直達**
   - 支援依**全台縣市**下拉選單快速篩選。
   - 支援車輛標題與品牌型號**模糊關鍵字**搜尋（不區分大小寫，支援 Enter 鍵快速搜尋）。
   - **欄位表頭智慧排序**：點擊「所在縣市」、「車款完整名稱」、「出廠年份」、「行駛里程」、「售價」表頭即可依數值/文字升降序切換。
   - **雙擊車源直達**：在表格上雙擊任意車源，立即自動以預設瀏覽器開啟該車在 8891 的原始網頁！
   - 一鍵「📥 匯出查詢結果 (CSV)」，將當前篩選之車輛清單匯出為 Excel 相容的 UTF-8-SIG CSV 檔。
   - 一鍵「顯示全部」重置篩選狀態。

2. **清爽高效的清單檢視**
   - 採用 `Treeview` 結構化呈現，底層以 `itertuples` 高效虛擬化載入近 4 萬筆資料，不卡頓。
   - 內建垂直捲軸滾動支援，狀態列即時反饋搜尋筆數與載入來源。

3. **大數據行情智慧估價與報表產出**
   - 輸入車款關鍵字（如 `Altis`、`RAV4`、`C300`）與出廠年份。
   - 支援輸入「預計行駛里程」，系統自動比對市場同型車平均里程，給出「里程高/低於均值」之修正提示。
   - 自動運算並產生詳細報告：**參考樣本數**、**市場平均行情價**、**合理開價區間（最低~最高價）**、以及**買賣建議議價空間（-5% ~ -10%）**。
   - **📥 匯出參考車源明細 (CSV)**：將本次估價作為參考依據的所有相似車輛清單完整匯出。
   - **📑 儲存估價紀錄至歷史報表 (CSV)**：自動將歷次估價紀錄追加儲存至 `valuation_history.csv`。
   - **📊 一鍵開啟歷史報表**：直接調用系統預設軟體（如 Excel）開啟估價歷程。

4. **雙軌資料來源彈性載入 (SQLite + CSV)**
   - 頂部設有「📂 載入 CSV 檔案」與「🔄 重新載入 SQLite」按鈕，支援隨時切換與即時熱載入。
   - 智慧相容多種編碼（UTF-8-SIG、UTF-8、CP950、Big5）與各類欄位別名（`車輛連結`/`超連結`/`價格_元`/`里程_km`）。
   - 容錯機制：若無 SQLite 資料庫，自動嘗試載入目錄下的 `8891_cars.csv` 備用。

5. **整合爬蟲與資料分析模組**
   - 提供獨立的採集儀表板 (`crawler_gui.py`) 與命令列自動化管線 (`crawler_pipeline.py`)，兼顧自動化爬取、資料清洗與商業圖表繪製。

## 🛠️ 環境需求與安裝

### 1. Python 版本
- 建議使用 **Python 3.8** 或以上版本（支援 Windows / macOS / Linux）。

### 2. 安裝必要依賴
本專案 GUI 使用 Python 內建的 `tkinter`，資料庫使用內建的 `sqlite3`。其餘資料處理、爬蟲與視覺化套件可透過 `requirements.txt` 一鍵安裝：

```bash
pip install -r requirements.txt
```



## 📖 功能操作說明

### 1. 車源快速查詢、排序與網頁直達
- 點選切換至 **「🔍 車源快速查詢」** 分頁。
- **縣市篩選**：從下拉選單選擇特定縣市（例如「新北市」），預設為「全部縣市」。
- **關鍵字搜尋**：在輸入框輸入車款、品牌或規格關鍵字（例如 `CR-V`、`Focus`、`油電`），按下 **「查詢」** 或直接按鍵盤 **Enter**。
- **表頭排序**：點擊欄位表頭（如「售價」或「行駛里程」），即時以數值大小進行升降冪排序。
- **雙擊直達網頁**：雙擊任一筆車輛，立即自動在預設瀏覽器中開啟該車於 8891 的原始車源頁面。
- **📥 匯出查詢結果 (CSV)**：點選右上方按鈕，即可將當前搜尋結果以 UTF-8-SIG CSV 儲存至指定路徑，Excel 開啟不亂碼。
- **恢復顯示**：點擊 **「顯示全部」** 即可清除搜尋條件並重置所有列表。

### 2. AI 智慧估價系統與報表儲存
- 點選切換至 **「💰 AI 智慧估價系統」** 分頁。
- **車款關鍵字**：輸入欲估價的品牌或型號（例如 `RAV4`、`Altis`、`C300`）。
- **出廠年份**：輸入西元年份（例如 `2019`）。
- **預計行駛里程（選填）**：輸入目標公里數（例如 `65000`）。
- 點選 **「🚀 開始智慧估價與市場行情分析」** 按鈕或在輸入框按下 **Enter**。
- **報告產出**：
  - **參考樣本數**：統計資料庫/CSV 內符合該型號與年份的車源總量。
  - **市場平均行情價**：以全體符合車源之平均價計算。
  - **合理開價區間**：呈現市場最低與最高價格分佈。
  - **里程修正提示**：若有輸入里程，系統將比對市場平均值並提示偏高或偏低狀況。
  - **建議議價空間**：提供業界建議折讓空間（-5% ~ -10%）。
- **CSV 相關操作**：
  - **📥 匯出參考車源明細 (CSV)**：將所有符合該估價條件的車輛樣本清單完整匯出至 CSV。
  - **📑 儲存估價紀錄至歷史報表 (CSV)**：一鍵追加記錄至 `valuation_history.csv`，方便比對追蹤。
  - **📊 開啟歷史估價報表**：一鍵開啟歷史估價檔案進行檢視。

### 3. 多來源資料切換 (SQLite / CSV)
- **載入 CSV 檔案**：點擊右上角 **「📂 載入 CSV 檔案」**，可選取任意外部 CSV 車源檔案，系統自動完成編碼判定、欄位對齊與數值正規化。
- **重新載入 SQLite**：點擊 **「🔄 重新載入 SQLite」**，可快速重新連線 `auto8891.db` 讀取最新資料庫內容。

### 4. 自動化爬蟲採集儀表板與商業分析管線
- 執行 `crawler_gui.py` 可開啟獨立的爬蟲採集控制台，支援設定頁數、一鍵離線模式測試，採集後自動匯出 `cars_market.db` 與 `8891_gui_export.csv`，並可點擊「📊 檢視折舊分析圖」即時繪製散佈圖。

## ⚙️ 核心演算法與設計細節

### 1. 數值清洗機制 (`to_number`)
由於爬取的原始字串包含中文單位（如「`52.8萬`」、「`6.5萬公里`」），程式使用正則表達式進行結構化轉換：
- 抽取數值與小數點。
- 遇「萬」單位則自動乘以 10,000，將字串正規化為標準整數，以便進行高效率的 Pandas 數值統計與均值計算。
- 支援數值型別容錯，若傳入已清洗之浮點數或整數直接相容轉換。

### 2. 估價分析邏輯 (`calculate_valuation`)
- **兩階段篩選**：先以字串比對命中車款標題，再篩選符合年份之車源，並過濾掉無效開價（價格 $\le 0$）。
- **里程偏移率**：計算 $Target\_KM - Mean(DB\_KM)$，輔助評估該車輛是否為低里程優質車或高里程用車。

## ❓ 常見問題 (FAQ)

**Q1：匯出的 CSV 檔案在 Excel 開啟時中文呈現亂碼？**
- 本系統所有 CSV 匯出均使用 `encoding="utf-8-sig"`，內建 UTF-8 BOM 識別碼，以 Windows Excel 雙擊開啟保證繁體中文清晰無亂碼。

**Q2：若沒有 auto8891.db 資料庫能否使用？**
- 可以！系統具備自動探索備用機制，若找不到 SQLite 資料庫會自動載入同目錄下的 `8891_cars.csv`，您亦可隨時點擊「📂 載入 CSV 檔案」選取任何外部車輛 CSV 檔案進行查詢與估價。
